## Consumer audit (rule 2)
* GenericSave padding: readers of the file size / layout = `LoadWorkBuffer` (alignment + total), `CheckDataNotCorrupt` (checksum is the last dword of the file: now at offset 202748), `C_PcSave::PopulateSlotInfo` (header only), `SaveWorkBuffer(true)` (writes the checksum after the padded remainder). Pad bytes are the stale work buffer, as in the exe. Load of the new file verified in-game (s6c / FastLoader).
* Path buffers: only GenericGameStorage.cpp reads `ms_LoadFileName*`; `GenerateGameFilename` writes into them.
* Hand-signal dtor: no other reader.
Win32 view: `w0a_guardlines.py check` TEXT OK for GenericGameStorage.cpp / .h and TaskSimplePlayHandSignalAnim.cpp; audio_cmd.cpp + play_cmd.cpp + tools are portable-only. No 3-min Windows soak applies (Mac).
