## Tool changes (benefit later batches)
1. `globals_emit.py`: new type kind `wenum` for `notsa::WEnum<enum E, Store>` (canonical spelling from the probe): literal `static_cast<E>(N)` with N read in the signedness of `Store`
   (before: `std::bit_cast<notsa::WEnum<enum eModelID,unsigned short>>((uint16)0xFFFF)`). Also handled inside arrays (`zero_of`).
2. `codemod_globals.py`: **header `extern T& name;` declarations**. A namespace-scope `.cpp` definition that becomes a real object conflicts with the sibling header's
   `extern T& name;` in detached mode (reference vs object). The codemod now rewrites the single matching line of `<stem>.h/.hpp` to `NOTSA_GLOBAL_EXTERN(name, (T));`
   (single line, line-count preserving, reported as `EXTERN`; forms it cannot rewrite - arrays, several matches - are reported as `warn`). 44 headers contain
   `extern ...&` declarations (Camera.h 10, CdStreamInfo.h 11, Clouds.h 7, VehicleModelInfo.h 6, Audio managers, ...): later batches whose owner `.cpp` has such a header
   get it for free; declarations living in a header with a different stem than the .cpp still need a by-hand `NOTSA_GLOBAL_EXTERN`.
3. `Base.h`: `NOTSA_GLOBAL_EXTERN(name, (T))` = `extern T& name` (address mode, the old text) / `extern T name` (detached). Documented in the Base.h comment and the codemod docstring.
