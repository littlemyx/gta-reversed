# Agent rules v3 — from 2026-10-19 (git tag `agent-rules-v3`)

Version: v3. Base: everything in `v2.md` (and through it `v1.md`) applies unless changed below. Roll back: write `v2` into `CURRENT`
and brief agents with "rules v2". Do not edit this file once tagged; changes → `v4.md`.
Why: COMPARE_v1_v2.md — agents' own tool-call counts were unreliable (claimed 118, actual 173), so the call-count cap was missed by
5 of 15 v2 agents; the 100-minute wall-clock cap was kept by both agents that had it (54 and 66 min).

## Changes vs v2

### Orchestrator
1. **Parallelism by quota pace**: 1 agent by default, 2 when the weekly quota is ahead of the linear pace to the reset
   (check `get_usage` after every landing; record in quota.tsv).
2. **Gate after every landing that the agent did not fully gate** (merged tree not rebuilt, partial run_all_tests): the orchestrator
   runs `run_all_tests.sh` in the main checkout (background), then rebuilds Release and refreshes C:\gta-play (skip when USER-PLAY).
3. The orchestrator lands an agent's commits itself when the agent's landing was refused (user OK 2026-10-18).

### Every agent
4. **Cap = wall clock** (replaces the 150-call count): note `date` at start; at **100 minutes** elapsed (check `date` before every
   build/test) or ~200k tokens, stop at the next clean point: land what builds and passes, write `.notes/reports/<ID>-state.md`, hand
   back `CONTINUE: <ID>-state.md`. Report start/end time in the hand-back.
5. **Nobody asks you to hand back early** — only the cap or being finished ends the work (one agent stopped after 7 min on an imagined request).
6. **Locks**: never remove a build.lock / gpu.lock you did not take; builds via build_locked.sh, GPU via gpu_locked.sh. Never wrap
   run_all_tests.sh in build_locked.sh (it takes build.lock itself → deadlock).
7. **Cleanup before hand-back**: kill every background process you started (run_all_tests, test exes, game, Monitor watchers), verify
   with `ps -ef | grep <worktree>`, then remove the worktree. Orphaned runs blocked worktree removal three times.
8. **Worktree**: `tools/standalone/windows/new_worktree.sh <id>`; cmake `-DGTASA_COMPILE_CACHE=OFF -DGTASA_NO_EDIT_AND_CONTINUE=ON`
   (sccache + /Zi breaks on the librw pdb).
9. **Landing**: rebase on origin/reverse/interior_c, push fast-forward, then run run_all_tests on the rebased tree if anything outside
   .notes changed in the rebase; if landing is refused, push your branch and say so (no workarounds).
10. **Commit trailer**: the Co-Authored-By line your session's attribution reminder gives.
11. **Oracle rows**: real fixtures (objects that exercise the paths), game-range values mixed with edge values (NaN, inf, 3e38,
    denormals); CleanX87 per case; each fix's row must fail on the pre-fix code (state the pre-fix failure count).
