## 1. Audio div-by-0 (0xC0000094, CAEStreamThread::Service 0x4F1464)
Root cause = game DATA, not decoder creation. A native libvorbisfile scan of all 1922 TrakLkup entries (XOR table + the exe's CAEDataStream window semantics replicated,
tool in scratchpad s7/tl.c) finds 122 tracks (not 90 as the commit message says) with ov_time_total == 0: 4429-byte Ogg stubs (BOS + comment + setup + EOS page, granulepos 0) that
replace removed songs in the Steam macOS install (groups of 5-14 consecutive sound ids: 177, 294-300, 513-519, 527-533, 848-854, 883-889, 932-938, 1118-1124, 1152-1157, 1301-1314,
1556-1569, 1706-1712, 1741-1747, 1754-1767, 1782-1786, 1809-1813 = each song + its intro/outro ids). No other track is <= 1 s long. ov_open succeeds, so Initialise()==true and
GetStreamLengthMs()==0; the exe's `div ecx` (asm 0x4F1464, ecx = vtable+8) traps identically, the first time the radio picks a removed song (random, ~8% of picks).
The port's radio logic matches (sunny-banter bug etc. replicated), the track id is a legal choice. Fix (NOTSA, documented): LoadDecoder treats a zero-length decoder as a failed load
(delete -> nullptr, the exe's missing-file path). Validation: temporary hack forcing every radio track to stub 294 -> 38 rejects in a burst, no crash/hang, quit ok (hack not committed).
Note: a failed ambience/loading stream at game start hangs loading (seen when the hack also hit tracks 174/706/708) - unrelated, exe behaviour.
Crashing track id itself was not captured (the crash soak's log has no id); the stub set is the only way to get length 0.

## 2. Quit
The quit path is fine in our build: ESC -> QUIT GAME -> YES exits through atexit (8 runs). Failure cause = injector: when a frame stalls, the pump pushed ESC down and up in the same
call, the pad saw no press, so the pause menu never opened (screenshots mark_quit_* in the failing run showed the plain game view; the first failure ended in LOAD GAME because a
stray real mouse pointer / hover picked another menu item - route now hovers QUIT GAME (mouse:480,440) instead of UP). Fix 7009615d: key-up is deferred until >= 150 ms and 2 game
frames after the down was really injected. Verified under 3 fps machine load (load avg 250): quit worked.
