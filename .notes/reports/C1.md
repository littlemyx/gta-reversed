## Findings
1. `CAEWeaponAudioEntity::Constructor` (0x5DE990) constructs a temporary (`T::T();` without `this->`); `*this` stays untouched. Behaviour kept, `// BUG:` comment added, fix left to the audio batch / `IsFixBugs`.
2. `RH_ScopedGlobalInstall` on member functions (9 sites) and a `CPool` friend `swap` naming a non-existent member (never instantiated).
3. X87Intrinsics.h, IdleCam.cpp, BoneNode.cpp, Fp.h are guarded `!__clang__`: the clang-cl objects use the `std::` fallback there (gate only, not a fidelity build).
4. `fakerw.h` static_asserts compare different enum types: error with `-std=c++2c` (fine with CMake's c++23).
5. Apple libc++ lacks `views::enumerate` (129 uses), `ranges::shift_right`, `<stacktrace>`; `from_chars(double)` needs macOS 26.
6. clang native defaults that change numbers and are invisible as errors: `-ffp-contract=on` (FMA), `char` signedness, strict aliasing, MSVC right-to-left argument evaluation (plan slice C-8).
