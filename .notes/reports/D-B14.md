## B15 (commits 0db65b65 .. 855dc7a3)
Codemod: 115 GLOBAL, 7 LOCAL, 3 EXTERN (gnRendererModelRequestFlags, gpOutEntitiesForGetObjectsInFrustum, Scene), 2 HDR (RsGlobal, ScriptParams) + 1 DECL+DEF; plus by hand: Replay (below), the CommandHandlerTable DEF, three CVector_Reversed initialisers, dllmain.
Hand work / decisions:
* **RenderWare.h / rwcore.h / rpmatfx.h alt-only globals stay address mode**: `RwInitialized`, `RwEngineInstance` (the codemod had converted them), `geometryTKList`, `RpUVAnimDictSchema`, `AmbientSaturated`, `_RwD3DDevice`, `_rwD3D9Last*`, `MatFXMaterialDataOffset` are compiled only without `NOTSA_RW_LIBRW` (the plugin-sdk/DLL configuration with the exe's own RenderWare, probe_cfg `alt`); the run build uses the shim's storage (`source/standalone/rw/rwglobals.cpp`), nothing in the shim touches the converted RsGlobal. I reverted the two the tool had converted (a detached non-librw build is not a thing, and the dead branch would be unverified code). Only `RsGlobal` (probe_cfg run) is converted.
* `CRunningScript::s_OriginalCommandHandlerTable` (27 member-function pointers to the exe's `ProcessCommands0to99..` handlers): the emitter printed `static_cast<OpcodeResult (__thiscall CRunningScript::*)(int)>(0x00465E60U)` (parsed as an enum, does not compile). DEF written by hand with a detached-only helper `OrigHandler(va) = std::bit_cast<CommandHandlerFn_t>(va)`: the table keeps the exe addresses exactly like address mode (they hit the trap stubs; the handlers are not ported - only reached for commands without a port). Type spelled `CRunningScript::CommandHandlerTable_t` in the DEF.
* Replay: `bIsUsingRemoteCar` (Replay.h) owner + `static NOTSA_GLOBAL_ALIAS(s_FrameActiveLookAroundCamReset, 0x97f66d, (bool), CReplay::bIsUsingRemoteCar)` in ProcessLookAroundCam (the tool reported both as "undecided" because its aliases.json keys missed on Windows backslashes until ce3b2d29; with the fixed tool a re-run on both batches finds no further work). `CameraFocus/CameraFixed/LoadScene` (`CVector_Reversed` has no default ctor): `{ CVector{0,0,0} }`.
* dllmain.cpp: `*(RwCamera**)0xC1703C` = Scene.m_pRwCamera (0xC17038 + 4), a raw-cast stray: `#ifdef NOTSA_GLOBALS_DETACHED` Scene.m_pRwCamera / `#else` the original line, `#line 34` (NOTSA_GLOBAL_EXPR added a 5-byte COMDAT to the object, so the plain #ifdef was used).
Left address-mode (d): Replay `PlayerInfo`, RoadBlocks `RoadBlockNodes`, Scripted2dEffects `ms_effectPairs`, `ms_userLists`.
