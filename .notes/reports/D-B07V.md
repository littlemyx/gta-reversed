## Open items (all native-Windows, all reproduce on the pre-B07 option-OFF build, none caused by B07 / detach)
1. **Quit exits with a heap-corruption fast fail**: in the full route, ENTER on YES in the quit menu ends the process within 150 ms, no "atexit handler ran", MSYS rc 127; WER shows APPCRASH ntdll 0xC0000374 (STATUS_HEAP_CORRUPTION) at the quit of the detached run (00:13:59). The pre-B07 OFF build (worktree 7d1305b5 + the two fixes above) ends the same way (rc 127). Wine's heap hid it. Needs a debug-CRT / page-heap run (StandaloneRW) to find the offending free; suspects are in the shutdown path (CGame::Shutdown, AudioEngine.Shutdown, `free(argv)` in NOTSA_WinMain). Until fixed, soak.sh reports RESULT FAIL on Windows even for a clean run: judge by "errors: 0, markers reached, no Exception in log.log".
2. **Stencil shadow crash**: `CCollisionData::GetShadTrianglePoint` <- `BuildShadowVolume` <- `CStencilShadows::Process` AV at idle_start in 1 of 5 runs of the pre-B07 OFF build (not seen in the detached builds in 4 runs): pre-existing, flaky, probably an unvalidated triangle index / col pointer. Not investigated.
3. **Saved settings crash the next start**: a normal quit writes `Documents\GTA San Andreas User Files\gta_sa.set` (the directory did not exist before the first run; created by our runs, file deleted again at the end). Starting with that file (DisplayVideoMode=4) crashes in `CMenuManager::Initialise -> SetVideoMode -> RwD3D9ChangeVideoMode -> ResetDeviceNow -> librw releaseVideoMemory -> destroyVertexBuffer` (a dynamic-VB entry holds the value 1). Every run in this report started with the file deleted. soak.sh/census.py on Windows should delete it before a run (or use a private Documents).
4. Soak data dirs kept: C:/gta-soak-b07v (junction/hardlink data dir), outputs C:/gta-soak-out/b07v (dump.tsv, soak1/soak2, census.tsv, runs.txt), C:/gta-census-b07v-out. Worktree removed. No exe was committed.
