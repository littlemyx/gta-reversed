## Consumer audit
* CRunningScript file bytes: only CTheScripts::Save/Load (TheScripts.cpp, per script: int16 index, record, u32 ip offset, 8 x u32 stack offsets), reached from GenericGameStorage. `grep sizeof(CRunningScript)`: only Windows oracle tests (x86 allocation size). m_BaseIP readers: CommandParser/Parser.hpp:69 (debug log), writers: MissionCommands.cpp:36, MissionDebugModule.cpp:161, StreamedScripts.cpp:91 (external scripts, never saved). tScriptParam is 4 B since P-2b.
* The ToFile/FromFile VA mapping assumes ScriptSpace is one contiguous array (it is: `std::array<uint8, SCRIPT_SPACE_SIZE>`, MissionBlock a span into it) - the same assumption the existing `m_IP - ScriptSpace.data()` offsets make.
* Behavioural note: scripts whose live m_BaseIP is null (e.g. normal scripts if CRunningScript::Init leaves it so) get BaseIP = ScriptSpace after a load instead of null (exe kept the saved value); only a debug log reads it.
