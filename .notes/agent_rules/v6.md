## Changes vs v5
1. **Portable coding rules for all new or changed source** — the table in `.notes/PORTABLE_GATE.md` section 2 is binding:
   - Win32 API / oracle / REPLAY / Lockstep / D3D9 / DirectSound code inside `#if !defined(NOTSA_PORTABLE)` (own lines);
   - `x87d` / `X87R(...)` / `X87W(...)` instead of `double` in PC24 math;
   - `NOTSA_FTOL` / `NOTSA_FTOL_SC` / `NOTSA_FTOL_FN` / `NOTSA_FTOL_P` for float→int conversions;
   - `VALIDATE_*` vs `VALIDATE_*_FILE`, `notsa::FileRecord<T>` for raw struct file I/O;
   - `NOTSA_PTR_ID32(p)` for pointers used as 32-bit ids, never a pointer cast to int32/uint32;
   - `sizeof` of the real type, never an x86 constant;
   - `NOTSA_UNREACHABLE_RET(value)` at the end of non-void functions.
2. **Pre-commit grep** (section 3 of PORTABLE_GATE.md) on your staged diff; every hit gets one of the spellings above or a guard.
3. When the orchestrator gate gains the `PortableWin64` compile step, agents that touch shared headers (Base.h, Vector.h, Timer.h,
   anything under source/game_sa/Core) run it too: 0 compile errors + link.
