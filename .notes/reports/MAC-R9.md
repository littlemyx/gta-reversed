## What
* `portable/render/pipelines_carenv_gl3.{h,cpp}` (rw-only, no game deps): `NotsaGl3CreateSaEnvPipeline(prepare, pluginId)` = rw::gl3::ObjPipeline with librw's default instance callback (1-v rule, UV sets, prelit re-upload for NVC) and its own render callback + shader pair (4 variants fullLight x alpha-test). Per mesh a game-side *prepare callback* fills `NotsaSaEnvMesh` (mode, env texture, sx/sy/u/v, factor, spec, power, blackColor, light dir). Meshes with no env and no specular draw with librw's own default shader (zero risk for plain materials). Shader: default.vert lighting (R6-3 look) + env uv per mode + per-vertex D3D FF specular of g_GameLight (non-local viewer, H = norm(L + (0,0,-1)) in view space, only N.L > 0, x spec x 0.65, added after the env stage) + for specular materials the extra D3D light terms (diffuse 0.25 N.L, ambient 0.75). Modes: CAR_CAM (camera-space normal through the texture matrix, projective: s = u + sx nx/nz, t = v + sy ny/nz, additive env*TFACTOR), CAR_WAVE (UV set 2 + offset, mix by TFACTOR alpha), BLD_CAM (raw camera normal xy as uv, texture transform disabled in the exe, additive * TFACTOR), BLD_CAM_DN (same, * lit vertex colour = D3DTA_DIFFUSE). Env sampler forced to WRAP (the exe does). The 3 parameter vectors use librw's matfx uniforms (u_fxparams / u_envColor / u_colorClamp), because a uniform registered after the stock shaders exist makes flushUniforms print "doesn't exist" on every draw.
* `portable/render/pipelines_saenv_game_gl3.cpp` (StdInc TU): the CPU half, a line-by-line copy of the per-mesh math of CCustomCarEnvMapPipeline / CCustomBuildingPipeline / CCustomBuildingDNPipeline::CustomPipeRenderCB (flags, noReflections / isBlownUp, spec = min(1, 1.85 gSpecIntensity * specularity * 2), power = 100 * specularity, fmod translation, wave OffsetU animation incl. AllocEnvMapPipeAtomicData / RenderFrame, TFACTOR bytes, isSpecialColor -> black). `NOTSA_R9_OFF=1` turns the pipelines off (stock pipelines, R-6 behaviour).
* Game wiring (3 MSVC-visible files, guard-only lines): CreatePipe of the three classes now assigns the gl3 pipeline under NOTSA_PORTABLE (`CustomPipeAtomicSetup` already stores `ObjPipeline` into atomics). The AtomicHasNVCPipeline tag logic of R-6 is unchanged. NVC (CPU day/night blend into the prelit array) works through this pipeline too (default instance callback), proven in the test and in game.
